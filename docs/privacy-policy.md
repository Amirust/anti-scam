# Privacy Policy

_Last updated: November 4, 2026_

This Privacy Policy explains what data the anti-scam Discord bot (the "Bot"),
operated by the maintainers of the
[anti-scam project](https://github.com/Amirust/anti-scam) ("we", "us"),
processes, why, and how long it is kept.

The Bot's source code is public. If you run your own instance, you are the
operator of that instance and responsible for its data handling; this policy
covers only the instance we operate.

## 1. Summary

- The Bot looks at **images** posted in servers it is in, to detect known scam
  images. It does **not** read, store or analyze the text of your messages.
- For almost all images, nothing is stored: the image is checked in memory and
  discarded.
- When an image is flagged, the Bot keeps Discord IDs and match details needed
  for moderation, and moderators may choose to keep a copy of the image to
  improve detection.
- We do not sell data, show ads, or share data with third parties beyond
  Discord itself.

## 2. Data we process

### Images

The Bot processes images from messages in servers it has been added to:
direct attachments, attachments of forwarded messages, and link previews
(embeds) generated by Discord. Link previews are fetched only through
Discord's own media proxy — the Bot never contacts third-party websites.

Images are downloaded, compared against a dataset of known scam images, and
discarded from memory once checked. Images that are not flagged are **not
stored**.

### Data stored when an image is flagged or reviewed

- **Reports in the server's admin channel.** When an image matches, the Bot
  posts a report with the image, the sender's Discord user and the matched
  dataset entry. These reports live in the server's Discord channel and are
  controlled by that server's moderators and by Discord.
- **Ban records.** Bans are applied through Discord; the matched dataset entry
  name is included in the audit-log reason.
- **Detection observations.** For experimental detection features, the Bot may
  record the server ID, channel ID, message ID and sender's user ID, a
  similarity score, the detection verdict, and — if a moderator labels the
  report — the label and the moderator's user ID.
- **Image copies.** When a moderator labels a report or explicitly adds an
  image to the dataset, the Bot may save a copy of that image, along with
  derived fingerprints (perceptual hashes and embeddings), to improve future
  detection.

### Server settings

For each server, the Bot stores the server ID and the ID of the configured
admin (notification) channel.

### HTTP API submissions

Where the HTTP API is offered, submitted images (or Discord CDN links to
them) are processed the same way as images in messages. Flagged submissions
are reported to a designated review channel. The client name from the API
token is recorded in reports and logs.

### Logs

The Bot keeps operational logs for debugging and abuse prevention. Logs may
include Discord IDs (server, channel, message, user), detection results and
error details. Logs do not include message text.

### What we do not collect

We do not collect message text, voice data, email addresses, IP addresses of
Discord users, payment information, or any data from servers the Bot is not a
member of.

## 3. Why we process data

- **Scam detection and moderation** — to find known scam images and take the
  actions server administrators enabled (ban, delete messages, report).
- **Improving detection** — labeled reports and moderator-added images help
  tune detection and reduce false positives.
- **Operating the Bot** — server settings and logs keep the Bot working,
  secure and debuggable.

Where applicable law requires a legal basis, we rely on the legitimate
interest of server administrators and their members in protecting
communities from scams and compromised accounts.

## 4. Sharing

We do not sell or rent data. Data is shared only:

- with **Discord**, as needed to operate the Bot (for example, posting
  reports, sending DMs and applying bans) — see
  [Discord's Privacy Policy](https://discord.com/privacy);
- with the **moderators of the server** where the image was posted, via the
  admin-channel reports;
- when required by law.

The dataset of scam image fingerprints may be published as part of the open
source project. It contains fingerprints and entry names, not user data.

## 5. Retention

- Images that are not flagged: not stored.
- Server settings: kept while the Bot is in the server; can be removed on
  request.
- Detection observations, image copies and logs: kept as long as needed to
  improve detection and operate the Bot, and deleted on request where
  feasible.
- Admin-channel reports and bans: stored by Discord and controlled by the
  server's moderators, not by us.

## 6. Security

Data is stored on infrastructure we control, with access limited to the
maintainers. Downloads are restricted to Discord's own hosts. No system is
perfectly secure, but we take reasonable measures to protect stored data.

## 7. Your choices and rights

- **Server administrators** can remove the Bot at any time; it then stops
  processing that server's content.
- **Users** can ask for the data related to their Discord user ID to be
  reviewed or deleted, and can raise disputes about an incorrect ban with the
  moderators of the server that banned them — bans are managed by each server,
  not by us.
- Depending on where you live, you may have additional rights (such as
  access, correction, deletion or objection). We will honor such requests as
  required by applicable law.

## 8. Children

The Bot is intended for use within Discord, which requires users to meet its
minimum age. We do not knowingly collect data from anyone below that age.

## 9. Changes to this policy

We may update this policy from time to time. The "Last updated" date above
reflects the latest version.

## 10. Contact

For privacy questions or data requests, open an issue on the project's
[GitHub repository](https://github.com/Amirust/anti-scam/issues). Issues are
public, so do not include personal data in them — ask for a private contact
channel instead and we will follow up.
